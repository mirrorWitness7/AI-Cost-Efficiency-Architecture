# Operator Playbook

This is for the **human side**.

## 1. Before You Type Anything

Ask:

1. *What is the real output I want?* (format + constraints)
2. *What context is actually needed?* (link to doc > paste the whole wiki)
3. *What is "good enough" for this run?* (don't over‑optimize drafts)

Write this in 1–3 bullet points. Then prompt.

## 2. Prompting Rules

- Prefer **one clear paragraph + bullet constraints** over essays.
- Tell the model what **not** to do (no long intros, no emojis, etc.).
- Use the **same skeleton** for recurring tasks and tweak parameters.

Example skeleton:

- Role  
- Goal  
- Inputs (links)  
- Constraints (style, length, safety)  
- Output format  

## 3. When Things Go Wrong

If you feel:

- "I’m typing too much again"  
- "We keep going in circles"  

Do a **manual collapse**:

1. Stop.  
2. Summarize in 3 bullets what you learned this round.  
3. Start a clean thread with those bullets as context.  

Log this as a **collapse event** in your efficiency tracker.
